# MythoFame

Unofficial website for MythoLogic Interactive content provided by the community.  
The website contains useful information and resources added by notable members.

## Planned

- Servers and players stats (like Mytho).
- Guides and resources for SFD (modding, textures, config files etc.).
- Pages dedicated to important projects (SFR, MBL, SFDCT, Chambafighters, MapWriter, etc.).
- Cosmetics online editor.
- Map and scripts headers editor.
- Unofficial workshop for textures, sounds, maps, scripts, sfdx, _mods (.dll files)_, etc.  
  (spiritual successor of sfdmaps).

This is the frontend code and it's available for public view.  
Backend services stay closed source (for now).
